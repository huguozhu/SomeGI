# SomeGI 后续路线图（2026-05-19）

> 本文档汇总 C 阶段闭合后的后续工作。已完成：M0–M8、M11、A（验证 +
> profile）、B（既有技术工业化打磨）、C（新工业技术）。M9/M10（硬件 RT）
> 因当前开发机 Intel UHD 770 缺 HW RT 推迟。
>
> 路线图分四阶段：
>   - **D**：现有技术 polish（降噪、变体、采样升级）
>   - **E**：新功能（场景能力、抗锯齿、雾、动画）
>   - **L**：Lumen-lite（UE5 Lumen 简化复刻；依赖 D.1/D.3/D.4 部分项）
>   - **F**：硬件依赖项（等换带 RT 的 GPU 后启用）
>
> 排序按"视觉性价比"建议；不强制顺序。

---

## D 阶段：现有技术 polish

### D.1 SDFGI 时序累积
- **痛点**：C.3 SDFGI 首版无时序、单帧 N 射线 → 高噪点。
- **方案**：reproject ssgiPrev → 当前帧 worldPos → 上帧 NDC → bilinear 取样
  → α-blend（α≈0.92）。复用 SSGI 已有的 ssgiPrev pipeline 与 reproject 逻辑。
- **难点**：SDFGI 的 N 射线方向是 cosine 半球随机，与 SSGI 的 ray march 同
  pattern，能直接套；reservoir 不需要重投影。
- **预估**：1 ~ 2 天；重用 SSGI 时序代码。

### D.2 ReSTIR DI 时序累积
- **痛点**：C.4 仅 spatial reuse；temporal reuse 是 ReSTIR 论文方差降低的核心。
- **方案**：
  - 保留上帧最终 reservoir B（再加一张 reservoir image 当 history）
  - 当前像素 worldPos → reproject 上帧 NDC → 取上帧像素的 reservoir
  - reservoirCombine 把 history reservoir 合并进当前帧 init 后的 reservoir
  - cap M_max（论文典型 20×当前帧）防权重无限累积
- **难点**：需 prevViewProj（已有）+ depth 拒绝 + normal 拒绝 + clip 边界处理。
- **预估**：2 ~ 3 天。

### D.3 GI temporal denoiser（SVGF / ReBLUR 风格）
- **目标**：边缘保持 + variance-aware blur，作 SDFGI/ReSTIR/SSGI 通用 denoiser。
- **方案**（SVGF 简化）：
  - 累积 1st / 2nd moments → variance estimate
  - À-Trous 多 pass 大半径滤波，σ 跟 variance/depth/normal 走
  - 与 GI 输出耦合度低（独立 compute pass）
- **预估**：3 ~ 5 天；最有"放大器"价值，所有 GI 通道都受益。

### D.4 SDFGI cascaded scrolling（Godot 4 完整版）
- **痛点**：当前单 cascade 跟 scene AABB；远景看不到、相机移出 grid 即失效。
- **方案**：4 级 cascade（128³ × 4 = 64 MB UDF）按 2× 距离 stride 摆，每级
  跟随相机 toroidal scrolling（每帧只刷新移入的 cell slab，不重建全卷）。
- **预估**：5 ~ 7 天；复杂度高、收益主要在大场景。

### D.5 VXGI 6-cone hemisphere
- **痛点**：当前 6 主轴近似 → cosine 加权偏离实际表面 N。
- **方案**：6 cone（1 中心 + 5 倾斜 30° 半球分布），按 N 旋转到 surface tangent
  frame，aperture 30° 重叠。论文 Crassin 配方。
- **预估**：1 ~ 2 天；仅改 lighting.slang 的 cone trace 段。

### D.6 ReSTIR 多光源拓展
- **痛点**：C.4 只 demo point lights，glTF 内 emissive triangles 没参与。
- **方案**：
  - CPU 提取 emissive 三角形（emissive 强度 > threshold）→ 转成 area light
    candidate，存 worldPos / normal / area / emissiveColor
  - shader 端：area light 采样改成 surface point sampling，pdf 含 area
  - 与 demo point lights 合并到同一 light SSBO；alphabet shaped。
- **预估**：3 ~ 4 天；含 light extraction CPU 代码。

### D.7 IBL specular GGX importance sampling
- **痛点**：当前 split-sum 近似（Karis 2013）—— 中等粗糙度有偏。
- **方案**：runtime importance sample N 条 GGX 半球射线 + 采 envCube；用
  multiple-bounce-energy-comp（Fdez-Agüera）补回能量损失。
- **预估**：1 ~ 2 天；与 PRT specular（D.8）有重合。

### D.8 PRT specular transfer
- **痛点**：当前 PRT 只 diffuse；SH16 已建好（C 阶段 B.10）但 l=3 项闲置。
- **方案**：用 SH16 投 specular transfer（光泽度高时更稀疏，需要 l=3）。
  对每个粗糙度 bucket 单独 bake 一份 transfer。
- **预估**：5 ~ 7 天；运行时多个 SH 卷积、UI 切粗糙度演示。

### D.9 LPV mid-cell GV 遮挡
- **痛点**：B.8 GV 只在 source/dest cell 查 occlusion，长跨度仍漏。
- **方案**：propagation 时沿 source→dest 中点采 GV → 多一层 occlusion 衰减。
- **预估**：半天；改 lpv_propagate.slang 一个采样点。

### D.10 DDGI probe relocation
- **痛点**：B.5 classification 只把卡墙的 probe 标 inactive；它们仍占空间。
- **方案**：每帧根据周围几何 minimum distance 平移 probe 几 cm（论文 RTXGI）。
- **预估**：2 ~ 3 天；需要 voxelGrid 距离场近似（可复用 SDFGI udf）。

## E 阶段：新功能（场景能力扩展）

### E.1 CSM 级联阴影
- **目标**：替换 / 补充 RSM 的单级 sun shadow（512² 太糙，远景接缝明显）。
- **方案**：3 ~ 4 级 cascade depth-only render，PCF 7×7 + slope-scale bias。
- **预估**：3 ~ 4 天。

### E.2 Hosek-Wilkie 程序化 sky
- **目标**：替代 HDR cubemap，sun 方向 / turbidity 联动。
- **方案**：CPU 算 Hosek 系数 → GPU 全屏 fragment shader 求 luminance；
  IBL prefilter 流程改成"每次 sun 改变重建 envCube"。
- **预估**：2 ~ 3 天。

### E.3 TAA
- **目标**：全局抗锯齿；与 D.3 GI denoiser 共享 history。
- **方案**：jittered projection + reproject + neighborhood clamping
  （Karis 2014 Unreal）。
- **预估**：3 ~ 5 天。

### E.4 体积雾 / 大气散射
- **目标**：froxel-based volumetric scattering（Frostbite 2015 Hillaire）。
- **方案**：3D 粒子 grid（160×90×64）→ 每 froxel 算 in-scattering / extinction
  → 沿视线 ray march integrate。可加 sun shadow 投到雾中。
- **预估**：4 ~ 6 天。

### E.5 Skinning + 简单动画
- **目标**：让 GI 跑动态角色场景（DDGI / ReSTIR 真正 shine 要动态）。
- **方案**：glTF skin / animation 解析 + compute skinning（vertex transform
  → ssbo）→ voxelize 时认动态 mesh 重做体素。
- **预估**：5 ~ 8 天。

## L 阶段：Lumen-lite（UE5 Lumen 简化复刻）

> Lumen 是 UE5 的混合 GI 系统：在不同距离 / 硬件能力下切换 SW / HW RT、
> Surface Cache、Screen Probes、World Probes 等代理。完整复刻是多人多年
> 工程；SomeGI 的目标是 **"Lumen-lite"** —— 复用现有 C.2 / C.3 / DDGI
> 基础设施搭一个能拿 80% 视觉效果的版本。
>
> 整体管线参考：Krzysztof Narkowicz / Daniel Wright "Lumen: Real-time
> Global Illumination in Unreal Engine 5"（SIGGRAPH 2022）。

### Lumen 核心数据流（参考）
```
Mesh Cards (offline bake)        Screen Probes (per-frame)
    |                                 |
    v                                 v
Surface Cache atlas  <---- ray -----  spawn ray
  (lit radiance)                       v
    ^                              hit:
    |                                查 Surface Cache
    +------- iterative relight        radiance
            (multi-bounce)            v
                                  SH9 投影
                                      v
                                  spatial+temporal filter
                                      v
                                  Final Gather (lighting.slang)
```

### L.1 Global SDF cascade（基础设施）
- **依赖**：D.4 SDFGI cascade scrolling（先做完 D.4）
- 4 级 cascade 128³，每级 2× 距离 stride，toroidal scrolling
- SW RT 流程的粗筛 ray accelerator

### L.2 Screen Probe pass
- 屏幕空间 16×16 grid 一个 probe（自适应密集：复杂区域 8×8）
- 每 probe 朝半球射 N=32 ~ 64 ray（cosine 加权）
- SW RT path：global SDF cascade sphere-step 找命中 → 采 voxelGrid radiance
- 命中点 radiance → SH9 投影
- 输出：屏幕 probe SH atlas（screen / 16² × 9 系数 × 3 通道 ~ RGBA16F atlas）

### L.3 Surface Cache 替代（voxelGrid 当 mini-card）
- **跳过完整 mesh card 系统**（最大工程债）；voxelGrid 已经是粗 lit-cell-cache
- 升级 C.2 multi-bounce relight 为 **ping-pong 多轮**：连续 N 帧迭代收敛
- 把 voxel 当 6-axis mini-card：每 voxel 存 6 个方向的 lit radiance 而非
  isotropic（需要 RGBA16F × 3 image，类似 B.6 各向异性 alpha 但存的是 RGB）
- iterative relight：每帧从 voxel→voxel cone trace 加一轮 bounce

### L.4 Probe filtering
- **依赖**：D.3 GI denoiser（先做完 D.3）
- Spatial：邻居 probe SH 加权融合（normal/depth weighting）
- Temporal：reproject 上帧 probe atlas → α-blend SH coefs
- 复用 SVGF moments / variance 框架

### L.5 Final Gather pass
- 每像素采屏幕 probe SH（trilinear in 16² screen grid）
- 半球 cosine-weighted 积分 SH → diffuse radiance
- lighting.slang 加一路 binding，按 m_giIndexApplied 切换

### L.6 World Probes fallback（远距离）
- 屏幕 probe 看不到的区域：复用 DDGI atlas（M11 已建）当 World Probes
- shader 端：probe 命中失败 → DDGI fallback

### L.7 Lumen Reflections（specular path）
- 单独 compute pass：屏幕空间 reflection ray 朝 reflection vector 发
- SW path：global SDF + voxelGrid radiance（替代 mesh card）
- 粗糙表面（roughness > 0.3）走 screen probe SH，不投 ray
- 时序累积 + spatial filter

### L.8（可选 / Phase L2）完整 mesh card 系统
- 离线烘 6 张正交 mesh card page / mesh
- card atlas（global 2D texture array，screen-res 子区分配）
- 替代 L.3 voxel 当 mini-card 的简化方案
- 工程量最大（占 Lumen 总工时一半），视觉提升主要在 specular / 高频细节

### L.9（可选 / Phase L3）HW RT path
- **依赖**：F.1（HW RT 可用）
- TLAS 替换 SW RT 的 SDF cascade
- BLAS = mesh，TLAS instance 携带 mesh ID → 反查 surface cache

### Lumen-lite 推荐启动序列

**Phase L1（4 ~ 6 周，最小可见版本）**：
1. 先打底：完成 D.1（SDFGI 时序）+ D.3（GI denoiser）+ D.4（cascade）
2. **L.2 Screen Probe pass** —— 屏幕 grid + SH9 投影
3. **L.3 voxel 当 surface cache** —— 升级 C.2 为多轮迭代 + 6-axis radiance
4. **L.4 probe filtering** —— 复用 D.3 denoiser 框架
5. **L.5 final gather** —— lighting 整合 screen probe SH

→ 拿到 Lumen 80% 视觉，工程量 ≈ SomeGI 当前工作量的 30 ~ 40%。

**Phase L2（再 6 ~ 8 周，工业完整度）**：
6. **L.7 Lumen Reflections**
7. **L.6 World Probes fallback**（DDGI 适配）
8. **L.8 完整 mesh card 系统**（最大工程债，但视觉细节最显著）

**Phase L3（等硬件）**：
9. **L.9 HW RT path** + **F.1 HW RT-DDGI** 一起做

## F 阶段：硬件依赖（被 GPU 阻塞）

### F.1 HW RT-DDGI（M9 / M10 复活）
- **前提**：换带 VK_KHR_acceleration_structure / ray_query 的 GPU。
- **方案**：见 `docs/superpowers/plans/2026-05-19-m9-rt.md`。

### F.2 RT Lumen surface cache（完整 Lumen，非 C.2 lite）
- **方案**：mesh card 系统 + surface cache atlas + RT 间接光更新；C.2 现有
  voxel relight 当 fallback。

### F.3 RTXGI 1.x 完整 DDGI
- **方案**：relocation + classification + variable rays/probe + state
  machine；当前 M11 / B.5 是子集实现。

## 推荐启动顺序

短期（高 ROI、单项 ≤ 3 天）：
1. **D.1 SDFGI 时序** — 直接降噪点，体感最明显
2. **D.2 ReSTIR 时序** — ReSTIR 论文核心收益项
3. **D.5 VXGI 6-cone** — 工业 cone trace 默认配方
4. **D.9 LPV mid-cell GV** — 半天的事

中期（≤ 1 周、放大器）：
5. **D.3 GI denoiser** — 所有 GI 通道受益
6. **E.3 TAA** — 与 D.3 共享 history，整体观感跃升

长期（多周、独立工程）：
7. **D.4 SDFGI cascade** + **E.4 体积雾** + **E.5 skinning** — 拓宽 demo
   能力
8. **D.6 ReSTIR area light** + **D.8 PRT specular** — 算法面拓展

巨型项目（L 阶段）：
9. 走完短期 + 中期后，可启 **Phase L1 Lumen-lite**（依赖 D.1 + D.3 + D.4）：
   L.2 screen probes → L.3 voxel surface cache → L.5 final gather → L.4
   filtering。完成后约等 Lumen 80% 视觉。

F 阶段等硬件。
