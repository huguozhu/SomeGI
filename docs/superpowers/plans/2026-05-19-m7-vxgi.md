# M7 — VXGI（Voxel Cone Tracing）实现计划

**Goal:** Crassin 2011 的 voxel cone tracing —— 把场景体素化到 128³ 3D 网格（每 cell 存 albedo + opacity），从 RSM 注入直接光把每 cell 变成"有方向的发光体素"，generate 8 级 mipchain，receiver 像素从屏幕空间出发沿 N 个 cone 方向 march 采 mip 累积间接光。比 LPV 强：cone 走 voxel 链时能拾取 occlusion，不漏光；比 RSM 强：不限于 sun frustum 内。

**M7 范围（单 cascade、isotropic mip）：**
- 128³ voxel grid（不做 256³ × 6 cascade clip-map —— 显存先扛得住、跑通再扩）
- 体素化用 compute scatter（per-triangle thread，AABB-voxel 写入），不用 geometry shader / 保守光栅
- 各向同性 mipchain（不做 anisotropic 6 方向 mips —— Crassin 真实方案的简化）
- 6 cone diffuse + 1 specular cone（粗略对应法线半球的离散方向）

**前置：**
- M5 RSM 已完成 —— light injection 阶段读 RSM。

**M7 不做：**
- Cascade（多分辨率 voxel）
- Anisotropic mipchain（6 个方向独立 mip）
- 真正的保守光栅（geometry shader 3-axis voxelize）—— 用 compute scatter 替代
- emissive surface 注入（只接 sun via RSM）
- 时序累积

---

## 资源 / 显存

- voxelGrid: VK_FORMAT_R16G16B16A16_SFLOAT，128³ + mip chain
  - mip 0: 128³ × 8B = 16 MB
  - mip total ≈ 16 × (1 + 1/8 + 1/64 + ...) ≈ 18.3 MB
- 每帧一次完整 voxelize + inject + mipmap 重建（不缓存 —— 简单优先）

## 阶段划分

### M7.0 — Voxel grid 资源 + 体素化

**Task 1: VxgiResources 类**
- File: `src/renderer/vxgi_resources.{h,cpp}`
- 持有 `Image voxelGrid`（128³，mip 全级）。
- create / destroy；提供 mip 0 view + per-mip storage views（mipmap 阶段用）。

**Task 2: vxgi_voxelize.slang + VxgiVoxelizePass**
- File: `shaders/gi/vxgi/vxgi_voxelize.slang`，`src/renderer/vxgi_voxelize_pass.{h,cpp}`
- compute shader：dispatch 三角形数 / 64。每 thread 一个三角形：
  1. 读三个顶点，转 worldPos。
  2. 取 triangle AABB → voxel index AABB。
  3. 双层循环 voxel 范围内每个 cell：用 SAT 或简化 (centroid in triangle) 测试是否相交；命中则 imageStore(albedo, 1)。
  4. last-writer-wins（多三角形落同 cell 只留一个 albedo —— 简化）。
- 实际上 SAT for triangle-AABB 太重 —— 退化为：把三角形采样 N 个点（重心三角形 + 边中点），每点直接打到对应 voxel。少数情况漏 cell 接受。
- bindResources：scene vertexBuffer + indexBuffer + materials + textures + voxelGrid mip0。

**Task 3: M7.0 验证**
- App stub 集成。debug：可视化 voxel grid mip0 切片（slice viewer）—— 或者跳过 viz，先确认 dispatch 不崩。

### M7.1 — Light injection from RSM

**Task 4: vxgi_inject.slang + VxgiInjectPass**
- 类似 LpvInjectPass 但写到 voxelGrid 而不是 SH 网格。
- 每 RSM texel：worldPos → voxel idx；voxelGrid[idx].rgb = albedo × flux（已含 NdotL · sunIntensity）；alpha 不变。
- 注：voxel 的 albedo 已经在 voxelize 阶段写过 —— inject 应该是 lit_radiance = voxel_albedo × incoming_sun。但 RSM flux 已经 = albedo × sunColor × NdotL。这里直接覆写 voxelGrid.rgb = flux 就行（voxelize 写的 albedo 阶段当 fallback 给没被 sun 照到的 voxel —— 它们 cone trace 时贡献 0）。
- 或者：voxelize 写 albedo+opacity；inject 写 lit_radiance = voxel_albedo × flux/albedo = flux（如果两者 albedo 一致）。简化：直接 inject 覆写 RGB。

### M7.2 — Mipmap 生成

**Task 5: vxgi_mipmap.slang + VxgiMipmapPass**
- compute shader：每级 mip 从上一级 8 个 voxel 平均（或 max-opacity-weighted）。
- dispatch 一个 mip level，循环到 mip max。
- 各向同性 (3D box filter)。

### M7.3 — Cone tracing 集成

**Task 6: lighting.slang +cone tracing path**
- Add bindings 14 = `gVoxelGrid` (Texture3D + linear sampler 已有 LPV 那个 sampler 复用)。
- counts.z=5 / lpvCounts.x[bit2]=VXGI flag。
- 6 cone（cosine-weighted 半球的 6 个 cluster 方向）：
  - 每 cone 沿方向 march N 步，每步 sample mip level = log2(coneDiameter / voxelSize)。
  - Beer's law 累积透明度，accumulated radiance 带 opacity 衰减。
- 输出 sumRadiance / N → indirect diffuse。

**Task 7: VXGI dropdown + UI + 验证**
- kGis 加 "VXGI" 实现项。
- ImGui：voxel viz 切片、cone count、step count、coneAngle。
- 验证：Sponza 模式色溢可见且带 occlusion 正确（不会穿薄墙漏光）。

## 风险

| 风险 | 退路 |
|---|---|
| compute scatter 体素化漏 cell 严重 | 改 dispatch granularity 更细（per-edge-midpoint），或退到 GS 真保守光栅 |
| 16MB voxel + mip 显存太大 | 降到 64³（2 MB）或换 RGBA8 |
| cone tracing 性能：6 cone × 32 step × per pixel 有点重 | 减 step、降 cone 数到 4 |
| Mip 生成和 voxelize/inject 之间的 barrier 链复杂 | 一次性做完整 mip chain 再 transition 到 SHADER_READ_ONLY |
| Voxelization 每帧重做太贵 | M7+ 加 dirty flag 跳过；M7 起步先做不缓存 |
