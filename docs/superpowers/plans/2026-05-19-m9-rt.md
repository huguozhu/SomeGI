# M9 — Ray Tracing GI 实现计划

> **状态：DEFERRED（2026-05-19）**。当前开发硬件 Intel UHD Graphics 770
> 不支持 VK_KHR_acceleration_structure / VK_KHR_ray_query 扩展（集成 GPU
> 没有硬件 RT 单元）。本计划保留作为 reference，待迁到带硬件 RT 的 GPU
> 后再实现。M10 ReSTIR 也依赖 RT，同步推迟或改用软件版本。


**Goal:** 用 Vulkan 硬件加速 ray tracing（KHR_acceleration_structure +
KHR_ray_query）做 1 spp 一次反弹漫反射间接光。compute shader 内通过
RayQuery API 直接发起 ray，命中点查贴图算 albedo · 直接 sun（带 shadow
ray）。**不用** 完整 RT pipeline (raygen/closesthit/miss SBT)，避免大段
shader-binding-table 模板代码。

**M9 范围：**
- 启用 KHR_acceleration_structure + KHR_ray_query + KHR_deferred_host_operations
- 一个 BLAS / primitive，TLAS 以 node·primitive 为 instance（每实例携带
  node.worldTransform），scene load 一次性构建（VK_BUILD_ACCELERATION_STRUCTURE_PREFER_FAST_TRACE）
- 1 spp cosine-weighted 半球 RT：每像素 1 ray 进 TLAS；若命中则 hit
  shading（fetch primitive material → albedo × sun direct，含 shadow ray
  到 sun），miss 用 IBL diffuse fallback
- 输出 rtGI（RGBA16F，rgb = bounced radiance，a = hit / miss），lighting.slang
  按 a lerp 到 IBL diffuse（与 SSGI / RSM 同 lerp 模式）
- 5×5 bilateral 过滤复用（已经在 lighting.slang）—— 不做时序累积（M9+）

**前置：** M5 RSM 已完成（RSM-style flux 写法可借鉴）；scene 已知 AABB / 顶点 / 材质。

**M9 不做：**
- 多反弹（M9 仅 1 bounce + 直接光）
- 时序累积 / TAA-like denoiser
- glossy reflections（仅 diffuse）
- 多光源 / 区域光（只接 sun）
- per-instance custom hit shaders

---

## 资源开销

- BLAS：Sponza ~200K 三角形 → 总 BLAS ~10-30 MB（每 primitive 一个）
- TLAS：1 instance/node-primitive，对 Sponza 单 node ~2 MB
- rtGI image：swapchain 大小 RGBA16F，~16 MB at 1080p
- 1 ray/pixel × 1080p × 60Hz = ~125 Mray/s，应该轻松

## 阶段划分

### M9.0 — 扩展 + AS 构建

**Task 1: device.cpp 启用 RT 扩展**
- VK_KHR_acceleration_structure (feature: accelerationStructure)
- VK_KHR_ray_query (feature: rayQuery)
- VK_KHR_deferred_host_operations
- 加载 RT 函数指针（vkCmdBuildAccelerationStructuresKHR 等）

**Task 2: SceneRtAS 类**
- File: `src/renderer/scene_rt_as.{h,cpp}`
- 接口：`build(Device&, oneShotPool, SceneCpu&, SceneGpu&)`
- 内部：
  1. 每 primitive 构建 BLAS：用 vertexBuffer + indexBuffer + 顶点偏移
     + 索引范围。VkAccelerationStructureGeometryKHR (TRIANGLES type)。
  2. 一次 vkCmdBuildAccelerationStructuresKHR 把所有 BLAS 一起 build。
  3. 每 (node, primitive) pair 生成一个 VkAccelerationStructureInstanceKHR
     （携带 node.worldTransform 转 3×4），写到 instance buffer。
  4. 构建 TLAS。
  5. 同时保留一个 InstanceData SSBO（每 instance：material index / vertex
     offset / first index / primitive base —— hit shader 端 fetch 材质用）。

**Task 3: SceneRtAS 集成**
- App 在 `loadAndUploadScene` 后调 `m_rtAS.build(...)`
- destroy 在 App 析构时

### M9.1 — RT compute shader

**Task 4: rt_gi.slang**
- File: `shaders/gi/rt/rt_gi.slang`
- bindings:
  - 0: FrameUniforms
  - 1: gNormalRough, 2: gDepth (GBuffer 同 SSGI)
  - 3: TLAS (RaytracingAccelerationStructure)
  - 4: instances SSBO
  - 5: vertices SSBO, 6: indices SSBO, 7: materials SSBO
  - 8: linear sampler, 9: textures[]
  - 10: out rtGI image (storage)
- per pixel：
  - 重建 worldPos / N
  - 1 cosine-hemisphere sample → 方向 d
  - RayQuery init/proceed/commit
  - if hit：取 instance + triangle，重心插值得到 hit position / normal /
    UV → fetch material baseColor → 计算 sun direct light：
      - shadow ray to sun: RayQuery 从 hit 点出发朝 -sunDir
      - 命中 = 阴影 → contrib = 0
      - 通透 = sunBRDF · sun_color · sun_intensity
    contrib = albedo · sunBRDF
  - if miss：rgb = 0, a = 0（lighting fallback IBL）
  - 输出 rtGI = float4(contrib, isHit ? 1 : 0)

**Task 5: RtGiPass class**
- File: `src/renderer/rt_gi_pass.{h,cpp}`
- 同 SsgiPass 模式，extra binding TLAS + scene SSBO。
- record: bind + dispatch (W+7)/8 × (H+7)/8。

### M9.2 — Lighting 集成 + dropdown + 验证

**Task 6: lighting.slang +RT lerp**
- 加 binding 16 = `gRtGI` (Texture2D<float4>) — 与 SSGI 同模式
- `frame.flags ... rtEnabled` 控制是否 lerp
- diffuse = lerp(diffuse_after_LPV, applyIBLDiffuseBRDF(rtF.rgb, ...), rtF.a)
- 加入 5×5 bilateral 同步过滤

**Task 7: GI dropdown + verify**
- kGis[7]=RayTracing implemented
- App 编排：m_rtEnabled，每帧 record RtGiPass（前置：GBuffer SHADER_READ_ONLY、RSM 不需要、TLAS 已 build）
- 验证：None / IBL / SSGI / RSM / LPV / VXGI / PRT / RT 八档切换无 crash
- 临时默认 RT，5 秒跑通无 validation error
- 切回默认 None

## 风险

| 风险 | 退路 |
|---|---|
| GPU 不支持 ray query | 编译时检查 features.rayQuery，构造时 throw 提示 |
| BLAS build 内存爆 | 限制 fastBuild + 后续可改 fastTrace |
| 1 spp 噪点过强 | 5×5 bilateral 已经在；M9+ 加时序累积 |
| TLAS instance buffer 上传慢 | 用 staging buffer + 一次 build；scene 切换才重 build |
| TLAS instance 携带的 customIndex 32 bit 不够 indexing material | 用 sbtRecordOffset 或单独 instances SSBO |
