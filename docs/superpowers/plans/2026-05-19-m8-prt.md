# M8 — PRT（Precomputed Radiance Transfer）实现计划

**Goal:** 实现 Sloan 2002 PRT 的体素简化版 —— 启动一次性 bake 每个体素的
"visibility transfer"（SH order-1 = 4 系数）；运行时把光源投影到 SH，
和 transfer SH 做点积得到带遮挡的 diffuse 入射辐射。区别于 LPV / VXGI：
**transfer 与光源无关**，太阳方向 / 强度变化时**不重 bake**，只重新投
影 lightSH（CPU 端开销几乎为 0）。

**M8 范围（与 spec 对齐）：**
- 32³ 体素 PRT volume（不是 per-vertex —— vertex baking 在 deferred 路径
  里需要把 SH 透过 GBuffer 难度大；spec 也允许 `先实现 vertex baking 版本`
  这是定向之处的偏离，记在 commit log）。
- SH order-1（4 系数）。spec 说 SH9，简化为 SH4（diffuse 视觉差异不大，
  bake 显存 / 算量减半）。
- visibility 测试用 M7 已有的 voxel grid。需要先 voxelize 再 bake；bake 后
  voxel grid 可以被 VXGI 模式覆写，PRT transfer 不依赖 voxel grid 实时状态。
- 光源 = sun（directional），CPU 端把 (dir, color, intensity) 投到 SH。

**前置：** M5 RSM ✓（VXGI 需要）；M7 VXGI voxelize/mipmap ✓（PRT bake 用）。

**算法回顾（PRT shadowed diffuse）：**

直接光传递公式：E(x, N) = ∫ L(d) · max(0, N·d) · V(x, d) dω

SH 投影分解：
  L(d) ≈ Σ_k l_k Y_k(d)              （光源 → light SH）
  V(x, d) ≈ Σ_k v_k(x) Y_k(d)        （visibility → transfer SH，bake 这个）

近似（SH 三积分 → element-wise）：
  E(x, N) ≈ max(0, Σ_k l_k · v_k(x) · A_l(k) · Y_k(N))

其中 A_l = (π, 2π/3, 2π/3, 2π/3) 是 Ramamoorthi/Hanrahan clamped-cos 卷积系数。

bake：v_k(x) = (4π/N) Σ_i V(x, d_i) · Y_k(d_i)
       d_i 取均匀球面采样；V 用 voxel grid alpha march。

light SH（每帧 CPU 计算 push 到 FrameUBO）：
  l_k = sun_intensity · sun_color · Y_k(d_sun)

## 阶段划分

### M8.0 — PrtResources + bake 资源
- File: `src/renderer/prt_resources.{h,cpp}`
- 1 张 RGBA16F 32³ 3D image，RGBA = SH 0..3。

### M8.1 — bake compute
- File: `shaders/gi/prt/prt_bake.slang`，`src/renderer/prt_bake_pass.{h,cpp}`
- compute dispatch 32³ thread。每 thread = 一个 cell：
  - 取 cell center 世界坐标
  - 64 个 Hammersley 均匀球样本
  - 每样本 d_i：march voxel grid（mip 0 用 alpha 当 occluder），到 transmittance 阈值或飞出 grid 当 visible
  - 命中 → V=0；通透 → V=1；累加 V·Y_k(d_i)
  - 输出 (4π/N)·Σ 写到 transfer image cell

### M8.2 — Bake 编排（App 一次性）
- 触发时机：scene load 完成后，第一次进入 main loop 前。
- 流程：voxelize（强制跑一次，不管 m_vxgiEnabled）→ mipmap（同上）→ prt_bake → 转 transfer 到 SHADER_READ_ONLY。
- 用 oneShotSubmit 的 helper 包起来，与帧管线分离。

### M8.3 — Lighting 集成 + dropdown + UI
- shared_types.slang FrameUniforms 加 `float4 prtLightSH_R/G/B`（SH4 × 3 channels）+ `int4 prtCounts`（gridResolution / enabled / pad）+ `float4 prtGridMinCell`。
- lighting.slang binding 15 = `gPrtTransfer` (Texture3D)。
- prtCounts.y!=0 时：trilinear 采 transferSH，element-wise mul lightSH·A_l，重建 irradiance(N)，加到 diffuse。
- App: kGis "PRT" implemented；effective==6 → m_prtEnabled。CPU 每帧投 lightSH。

### M8.4 — 验证
- None / IBL / SSGI / RSM / LPV / VXGI / PRT 七档切换无 crash
- bake 完成后切 PRT 模式：sun 方向变动时（拖 ImGui sun dir），间接光强度跟随；屋内被遮挡的角落更暗
- validation clean

## 不做
- per-vertex / per-texel bake（M8 用 volume 版）
- SH9 order-2（M8 用 SH4 order-1）
- Multi-bounce（只直接 visibility）
- glossy PRT / 环境光 SH 投影（用 sun 替代 env）
