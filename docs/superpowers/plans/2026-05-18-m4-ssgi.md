# M4 — SSGI（屏幕空间全局光照）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把"间接光"从纯 IBL 升级为"IBL + 屏幕空间增强"，引入 GBuffer prepass + Deferred Lighting 作为后续 M5–M8 的公共底座，并实现 SSAO（屏幕空间环境光遮蔽）、SSR（屏幕空间反射）、SSGI diffuse（一次反弹）三类屏幕空间技术。

**Architecture:**
- 新增 **GBufferPass**（graphics, MRT）：把场景的 albedo / metallic、normal / roughness、emissive / AO 写入 3 张离屏图。M4 之前 forward 直接计算光照写 hdrColor；M4 之后 forward 仅作场景几何 → GBuffer 的"几何阶段"。
- 新增 **LightingPass**（compute）：消费 GBuffer + IBL Set=1 + （可选）SSGI 输出，per-pixel 计算 direct sun + indirect (IBL × AO + SSR + SSGI diffuse)，输出到 hdrColor。
- 新增 **SsaoPass / SsrPass / SsgiPass**（皆 compute，按需启用）：从 GBuffer + 上一帧 hdrColor 派生屏幕空间间接光信号，写入小体积辅助贴图，由 LightingPass 读取。
- ImGui "GI" 下拉框中 "SSGI" 可点了；下面有子面板分别开关 SSAO / SSR / SSGI diffuse、调采样数 / 半径 / 步长。
- 透明物体的 ForwardPass 暂不做（spec §4.3 的"transparent forward"延后到 M9+）。Sponza 的 alpha-blend 材质短期内当作 alpha-mask 处理（discard），M4 不引入 blend。

**Tech Stack:** Vulkan 1.3 (compute, dynamic rendering, MRT), slang, glm。

**验证标准（来自设计文档 §9 + 本计划补充）:**
1. **M4.0 完成**：GBuffer + Deferred 重构后，cube/Sponza 的视觉与 M3 完全一致（可截图肉眼对比）。
2. **M4.1 完成**：开关 SSAO 时，Sponza 拱顶/拐角内侧明显变暗；cube 的接地处（cube ↔ ground 交界）有暗化。
3. **M4.2 完成**：cube（已设为光滑金属）开 SSR 时反射出地面/Sponza 几何的几乎像素对齐镜面；roughness 增大时反射模糊；屏外内容 fallback 到 IBL specular。
4. **M4.3 完成**：Sponza 中红色帘布旁边的白柱出现微弱红色 bounce；cube 旁边地面附近有蓝绿（cube 的 baseColor）色溢。

**M4 不做** —— 防止范围蔓延：
- Motion vectors / 时序累积（temporal reuse）：M7 RT 时再做（动机：RT 对噪声敏感）。
- Octahedral / RGBM 法线压缩：M4 用裸 R16G16B16A16_SFLOAT 法线，M5/M7 显存吃紧再压。
- Hi-Z mip chain：M4.2 SSR 用线性 ray march + 简单二分，跑通后再考虑 Hi-Z 加速。
- 透明 ForwardPass：见 Architecture。
- Bent normals / multi-bounce SSGI：M9+ 才有意义。

**关键尺寸 / 格式（默认值，可在常量里调）:**
- GBuffer RT0 "Albedo+Metallic"：`VK_FORMAT_R8G8B8A8_UNORM`（rgb=baseColor linear, a=metallic）
- GBuffer RT1 "Normal+Roughness"：`VK_FORMAT_R16G16B16A16_SFLOAT`（xyz=world normal normalized, w=roughness）
- GBuffer RT2 "Emissive+AO"：`VK_FORMAT_R8G8B8A8_UNORM`（rgb=emissive 受限于 8-bit；高强度 emissive 对 M4 罕见 OK）
- Depth：复用现有 `VK_FORMAT_D32_SFLOAT`
- SSAO 输出：`VK_FORMAT_R8_UNORM`（half-res 可选；M4.1 先 full-res）
- SSR 输出：`VK_FORMAT_R16G16B16A16_SFLOAT`（rgb=反射颜色 / IBL fallback, a=屏幕命中置信度 [0,1]）
- SSGI 输出：`VK_FORMAT_R16G16B16A16_SFLOAT`（rgb=单次反弹 diffuse, a=hit count → 暂用作 spatial filter 权重）

```hlsl
// 编码、解码约定（保持 M4 单一处声明，避免 shader 间漂移）
// RT0: rgb = baseColor linear, a = metallic
// RT1: xyz = world normal normalized, w = roughness
// RT2: rgb = emissive (clamped to [0, 1] in M4; HDR emissive 视后续需要再扩), a = AO

struct GBufferOut {
    float4 rt0 : SV_Target0;   // albedo + metallic
    float4 rt1 : SV_Target1;   // normal + roughness
    float4 rt2 : SV_Target2;   // emissive + ao
};

// helper：把法线从 [-1,1] 写入 R16G16B16A16_SFLOAT，无需 pack
GBufferOut packGBuffer(float3 baseColor, float metallic,
                      float3 worldNormal, float roughness,
                      float3 emissive, float ao) {
    GBufferOut o;
    o.rt0 = float4(baseColor, metallic);
    o.rt1 = float4(normalize(worldNormal), roughness);
    o.rt2 = float4(saturate(emissive), ao);
    return o;
}
```

- [ ] **Step 2: shaders/gbuffer/gbuffer.slang**

整体复制现 `forward_ibl.slang` 的 vs_main，不动；ps 只采样材质 + 法线计算，不算光照。

```hlsl
import shared_types;
import gbuffer_layout;

[[vk::binding(0, 0)]] ConstantBuffer<FrameUniforms> gFrame;
[[vk::binding(1, 0)]] StructuredBuffer<MaterialGpu> gMaterials;
[[vk::binding(2, 0)]] SamplerState gLinear;
[[vk::binding(3, 0)]] Texture2D gTextures[];

[[vk::push_constant]] PushConsts gPC;

struct VsIn {
    float3 pos     : POSITION;
    float3 normal  : NORMAL;
    float4 tangent : TANGENT;
    float2 uv0     : TEXCOORD0;
};

struct VsOut {
    float4 svPos    : SV_Position;
    float3 worldPos : TEXCOORD0;
    float3 normal   : TEXCOORD1;
    float4 tangent  : TEXCOORD2;
    float2 uv       : TEXCOORD3;
    nointerpolation int matIndex : TEXCOORD4;
};

[shader("vertex")]
VsOut vs_main(VsIn i) {
    VsOut o;
    float4 wp = mul(gPC.model, float4(i.pos, 1.0));
    o.worldPos = wp.xyz;
    o.svPos = mul(gFrame.viewProj, wp);
    float3x3 n3 = (float3x3)gPC.model;
    o.normal  = normalize(mul(n3, i.normal));
    o.tangent = float4(normalize(mul(n3, i.tangent.xyz)), i.tangent.w);
    o.uv = i.uv0;
    o.matIndex = gPC.materialIndex;
    return o;
}

float4 sampleTex(int idx, float2 uv) {
    if (idx < 0) return float4(1, 1, 1, 1);
    return gTextures[idx].Sample(gLinear, uv);
}

[shader("pixel")]
GBufferOut ps_main(VsOut i) {
    MaterialGpu m = gMaterials[i.matIndex];

    float4 baseTex = sampleTex(m.baseColorTex, i.uv);
    float4 base = m.baseColorFactor * baseTex;
    if (m.alphaMode == 1u && base.a < m.alphaCutoff) discard;

    float metallic = m.metallicFactor;
    float roughness = m.roughnessFactor;
    if (m.mrTex >= 0) {
        float3 t = gTextures[m.mrTex].Sample(gLinear, i.uv).rgb;
        roughness *= t.g;
        metallic  *= t.b;
    }
    metallic = saturate(metallic);
    roughness = saturate(roughness);

    float3 N = normalize(i.normal);
    if (m.normalTex >= 0) {
        float3 nm = gTextures[m.normalTex].Sample(gLinear, i.uv).rgb * 2.0 - 1.0;
        nm.xy *= m.normalScale;
        float3 T = normalize(i.tangent.xyz);
        float3 B = normalize(cross(N, T) * i.tangent.w);
        N = normalize(T * nm.x + B * nm.y + N * nm.z);
    }

    float ao = 1.0;
    if (m.occlusionTex >= 0) {
        float t = gTextures[m.occlusionTex].Sample(gLinear, i.uv).r;
        ao = lerp(1.0, t, m.occlusionStrength);
    }

    float3 emi = m.emissiveFactor;
    if (m.emissiveTex >= 0) emi *= gTextures[m.emissiveTex].Sample(gLinear, i.uv).rgb;

    return packGBuffer(base.rgb, metallic, N, roughness, emi, ao);
}
```

## Task 4: lighting.slang —— deferred 光照 compute

**Files:**
- Create: `shaders/lighting/lighting.slang`

输入：set=0 = FrameUBO + GBuffer 3 张 + depth + ibl (set=1, 复用现 `ibl_eval.slang` 的 set=1 binding 0..3)。
输出：`hdrColor` storage image。

- [ ] **Step 1: shaders/lighting/lighting.slang**

```hlsl
import shared_types;
import pbr;
import ibl_eval;        // 复用：set=1 IBL 资源 + evalIBL

[[vk::binding(0, 0)]] ConstantBuffer<FrameUniforms> gFrame;
[[vk::binding(1, 0)]] Texture2D<float4> gAlbedoMetal;
[[vk::binding(2, 0)]] Texture2D<float4> gNormalRough;
[[vk::binding(3, 0)]] Texture2D<float4> gEmissiveAO;
[[vk::binding(4, 0)]] Texture2D<float>  gDepth;
[[vk::binding(5, 0)]] SamplerState      gPointClamp;   // 重要：所有 GBuffer 用 nearest+clamp
[[vk::binding(6, 0)]] RWTexture2D<float4> gOutHdr;

struct LightingPC {
    uint2 outSize;
    float2 invOutSize;
};
[[vk::push_constant]] LightingPC gPC;

float3 worldFromDepth(uint2 pix, float depth, float4x4 invViewProj) {
    float2 uv = (float2(pix) + 0.5) * gPC.invOutSize;
    float2 ndc = uv * 2.0 - 1.0;
    float4 clip = float4(ndc, depth, 1.0);
    float4 w = mul(invViewProj, clip);
    return w.xyz / w.w;
}

[shader("compute")]
[numthreads(8, 8, 1)]
void cs_main(uint3 dt : SV_DispatchThreadID) {
    if (dt.x >= gPC.outSize.x || dt.y >= gPC.outSize.y) return;
    uint2 pix = dt.xy;

    float depth = gDepth.Load(int3(pix, 0));
    if (depth >= 1.0) {
        // 留给 skybox 填；为防 lighting 把 sky 区写脏，写 0
        gOutHdr[pix] = float4(0, 0, 0, 1);
        return;
    }

    float4 a = gAlbedoMetal.Load(int3(pix, 0));
    float4 n = gNormalRough.Load(int3(pix, 0));
    float4 e = gEmissiveAO.Load(int3(pix, 0));

    float3 albedo    = a.rgb;
    float  metallic  = a.a;
    float3 N         = normalize(n.xyz);
    float  roughness = n.w;
    float3 emissive  = e.rgb;
    float  ao        = e.a;

    float3 worldPos = worldFromDepth(pix, depth, gFrame.invViewProj);
    float3 V = normalize(gFrame.cameraPos.xyz - worldPos);

    float3 L = normalize(-gFrame.sunDir.xyz);
    float3 sun = directBRDF(N, V, L, albedo, metallic, roughness) *
                 gFrame.sunColor_intensity.rgb * gFrame.sunColor_intensity.w;

    float3 ibl = evalIBL(N, V, albedo, metallic, roughness, (float)gFrame.counts.y);
    ibl *= ao;

    gOutHdr[pix] = float4(sun + ibl + emissive, 1.0);
}
```

# M4.1 — SSAO

经典 HBAO-like：法线半球内若干方向上做 ray march，以"被遮挡的样本占比"作为 AO。

---

## Task 8: ssao.slang

**Files:**
- Create: `shaders/ssao/ssao.slang`

输入：法线（GBuffer RT1）+ depth → 重建 view-space pos → 半球采样若干方向 → 比较深度。

- [ ] **Step 1: shaders/ssao/ssao.slang**

```hlsl
[[vk::binding(0, 0)]] Texture2D<float4> gNormalRough;
[[vk::binding(1, 0)]] Texture2D<float>  gDepth;
[[vk::binding(2, 0)]] SamplerState      gPointClamp;
[[vk::binding(3, 0)]] RWTexture2D<float> gOutAO;

struct SsaoPC {
    uint2  outSize;
    float2 invOutSize;
    float4x4 invProj;          // view-space 重建用
    float4x4 view;
    float    radius;            // 世界单位
    float    bias;              // 与 depth 比较时的小偏移，避免自遮蔽
    uint     sampleCount;
    uint     _pad;
};
[[vk::push_constant]] SsaoPC gPC;

float3 viewPosFromDepth(uint2 pix, float depth) {
    float2 uv = (float2(pix) + 0.5) * gPC.invOutSize;
    float2 ndc = uv * 2.0 - 1.0;
    float4 clip = float4(ndc, depth, 1.0);
    float4 v = mul(gPC.invProj, clip);
    return v.xyz / v.w;
}

float hash(uint2 p) {
    p = p * 73856093u ^ p.yx * 19349663u;
    return float(p.x ^ p.y) * (1.0 / 4294967296.0);
}

[shader("compute")]
[numthreads(8, 8, 1)]
void cs_main(uint3 dt : SV_DispatchThreadID) {
    if (dt.x >= gPC.outSize.x || dt.y >= gPC.outSize.y) return;
    uint2 pix = dt.xy;
    float depth = gDepth.Load(int3(pix, 0));
    if (depth >= 1.0) { gOutAO[pix] = 1.0; return; }

    float3 vP = viewPosFromDepth(pix, depth);
    float3 wN = normalize(gNormalRough.Load(int3(pix, 0)).xyz);
    float3 vN = normalize(mul((float3x3)gPC.view, wN));

    // 在切线空间生成余弦加权半球样本
    float3 up = abs(vN.y) < 0.999 ? float3(0,1,0) : float3(1,0,0);
    float3 T = normalize(cross(up, vN));
    float3 B = cross(vN, T);

    float occ = 0.0;
    for (uint i = 0; i < gPC.sampleCount; ++i) {
        // 简化伪随机；M4.1 替换为 Hammersley 噪声更佳
        float2 xi = float2(hash(pix + uint2(i, i*7+13)),
                           hash(pix + uint2(i*13+5, i*5+91)));
        float r1 = sqrt(xi.x);
        float r2 = 6.2831853 * xi.y;
        float3 dir = float3(r1*cos(r2), r1*sin(r2), sqrt(1.0 - xi.x));
        float3 sampleDirVS = T*dir.x + B*dir.y + vN*dir.z;

        float3 vSamp = vP + sampleDirVS * gPC.radius;

        // 投影回屏幕
        float4 clip = mul(gPC.invProj, float4(vSamp, 1.0));   // 注：这里需要 proj
        // 见 Task 9 Step 2：实际我们传 invProj + proj 两个；上面字段名应为 proj
        // 此处保持示意；实现时把 invProj 改成 invProj+proj 两个矩阵。
        float2 ndc = clip.xy / clip.w;
        float2 uv = ndc * 0.5 + 0.5;
        if (uv.x < 0.0 || uv.x > 1.0 || uv.y < 0.0 || uv.y > 1.0) continue;

        uint2 sPix = uint2(uv * float2(gPC.outSize));
        float sampleDepth = gDepth.Load(int3(sPix, 0));
        float3 vRef = viewPosFromDepth(sPix, sampleDepth);

        // 距离衰减：与样本目标距离差距过大时不算遮挡（避免远处 false occ）
        float rangeCheck = smoothstep(0.0, 1.0, gPC.radius / max(abs(vP.z - vRef.z), 1e-3));
        if (vRef.z >= vSamp.z + gPC.bias) {
            occ += rangeCheck;
        }
    }
    occ /= float(gPC.sampleCount);
    gOutAO[pix] = saturate(1.0 - occ);
}
```

> 实现备注：上面示意里把 `invProj` 复用了两个语义；正确做法是在 PC 中同时携带 `proj` 与 `invProj`。本 shader 在 Task 9 实现里需调整。

```hlsl
// 输入：起点 (view space), 方向 (view space normalized), proj 矩阵
// 输出：命中？hit uv & depth，若 miss 返回 false
struct RayHit {
    bool   hit;
    float2 uv;
    float  depth;
};

bool projectViewToScreen(float4x4 proj, float3 vp, out float2 uv, out float depth) {
    float4 c = mul(proj, float4(vp, 1.0));
    if (c.w <= 0) return false;
    float3 ndc = c.xyz / c.w;
    if (any(abs(ndc.xy) > 1.0)) return false;
    uv = ndc.xy * 0.5 + 0.5;
    depth = ndc.z;
    return true;
}

RayHit marchScreen(float3 vOrigin, float3 vDir, float maxDist,
                   uint maxSteps, float thickness,
                   float4x4 proj, Texture2D<float> gDepth,
                   uint2 outSize) {
    RayHit r; r.hit = false;
    float t = 0.0;
    float dt = maxDist / float(maxSteps);
    [loop]
    for (uint i = 0; i < maxSteps; ++i) {
        t += dt;
        float3 p = vOrigin + vDir * t;
        float2 uv; float zNDC;
        if (!projectViewToScreen(proj, p, uv, zNDC)) return r;
        uint2 pix = uint2(uv * float2(outSize));
        float sceneDepth = gDepth.Load(int3(pix, 0));
        if (sceneDepth < zNDC && sceneDepth > zNDC - thickness) {
            // 命中：可加二分细化（省略）
            r.hit = true; r.uv = uv; r.depth = sceneDepth;
            return r;
        }
    }
    return r;
}
```

- [ ] **Step 4: shaders/ssr/ssr.slang**

```hlsl
import shared_types;
import screen_ray;
import ibl_eval;

[[vk::binding(0, 0)]] ConstantBuffer<FrameUniforms> gFrame;
[[vk::binding(1, 0)]] Texture2D<float4> gNormalRough;
[[vk::binding(2, 0)]] Texture2D<float>  gDepth;
[[vk::binding(3, 0)]] Texture2D<float4> gPrevHdr;
[[vk::binding(4, 0)]] SamplerState      gPointClamp;
[[vk::binding(5, 0)]] SamplerState      gLinearClamp;
[[vk::binding(6, 0)]] RWTexture2D<float4> gOutSsr;

struct SsrPC {
    uint2 outSize;
    float2 invOutSize;
    uint  maxSteps;
    float maxDist;
    float thickness;
    float roughThreshold;       // 大于这个 roughness 直接跳过（用 IBL）
};
[[vk::push_constant]] SsrPC gPC;

[shader("compute")]
[numthreads(8, 8, 1)]
void cs_main(uint3 dt : SV_DispatchThreadID) {
    if (dt.x >= gPC.outSize.x || dt.y >= gPC.outSize.y) return;
    uint2 pix = dt.xy;

    float depth = gDepth.Load(int3(pix, 0));
    if (depth >= 1.0) { gOutSsr[pix] = float4(0, 0, 0, 0); return; }

    float4 nr = gNormalRough.Load(int3(pix, 0));
    float roughness = nr.w;
    if (roughness > gPC.roughThreshold) {
        gOutSsr[pix] = float4(0, 0, 0, 0);   // confidence 0 → lighting 全用 IBL
        return;
    }

    // 重建 view-space pos & normal
    float2 uv = (float2(pix) + 0.5) * gPC.invOutSize;
    float2 ndc = uv * 2.0 - 1.0;
    float4 clip = float4(ndc, depth, 1.0);
    float4 vh = mul(gFrame.invViewProj, clip);   // 这是 world，需要 view 才好 march
    // 这里直接在 world 空间 march 也行；或者多传一个 invProj 改 view-space
    // M4.2 先用 world-space
    float3 wPos = vh.xyz / vh.w;
    float3 wN   = normalize(nr.xyz);
    float3 V    = normalize(gFrame.cameraPos.xyz - wPos);
    float3 R    = reflect(-V, wN);

    // 用 viewProj 做投影；也可以传 invProj 转 view-space 做更精的 march
    // 此处简化：用 wPos + R 直接迭代 + 投影
    float3 origin = wPos + R * 0.05;             // 小推开避免自相交
    float t = 0.0;
    float dt_step = gPC.maxDist / float(gPC.maxSteps);
    bool hit = false;
    float2 hitUv = float2(0);
    [loop]
    for (uint i = 0; i < gPC.maxSteps; ++i) {
        t += dt_step;
        float3 p = origin + R * t;
        float4 c = mul(gFrame.viewProj, float4(p, 1.0));
        if (c.w <= 0) break;
        float3 nd = c.xyz / c.w;
        if (any(abs(nd.xy) > 1.0) || nd.z < 0.0 || nd.z > 1.0) break;
        float2 sUv = nd.xy * 0.5 + 0.5;
        uint2 sPix = uint2(sUv * float2(gPC.outSize));
        float sceneZ = gDepth.Load(int3(sPix, 0));
        if (sceneZ < nd.z && sceneZ > nd.z - gPC.thickness) {
            hit = true; hitUv = sUv; break;
        }
    }

    if (hit) {
        float3 c = gPrevHdr.SampleLevel(gLinearClamp, hitUv, 0).rgb;
        float fade = 1.0;
        // 屏幕边缘 fade（避免硬剪）
        float2 e = abs(hitUv * 2.0 - 1.0);
        fade *= 1.0 - smoothstep(0.85, 1.0, max(e.x, e.y));
        // roughness fade
        fade *= 1.0 - smoothstep(gPC.roughThreshold * 0.5, gPC.roughThreshold, roughness);
        gOutSsr[pix] = float4(c, fade);
    } else {
        gOutSsr[pix] = float4(0, 0, 0, 0);
    }
}
```

# 工具链改进（强烈建议在 M4.0 之前/之中做）

## Slang import 依赖追踪

现在 `cmake/CompileSlang.cmake` 的 `add_custom_command DEPENDS ${SRC}` 只包含 entry-point；编辑 `common/*.slang` 不会触发依赖 entry 重编。M4 大量复用 `common/`（gbuffer_layout, screen_ray, normal_pack, ibl_eval），不修这点会反复手动删 spv。

修法：
- CMake configure 时扫描每个 entry-point 文件，正则匹配 `^\s*import\s+(\w+)`，递归解析 `common/<name>.slang`，把它们一并加入 `DEPENDS`。
- 等价做法：让 `compile_slang` 函数接收 `COMMON_DIR`，把 `${COMMON_DIR}/*.slang` 全部纳入 DEPENDS（粗粒度但简单 —— 共用组件总会牵连重编，仍比现在好）。

最小修改（粗粒度）：

```cmake
# cmake/CompileSlang.cmake
function(compile_slang TARGET_NAME)
    ...
    file(GLOB _common_deps "${CMAKE_SOURCE_DIR}/shaders/common/*.slang")
    foreach(SRC ${SLANG_SOURCES})
        ...
        add_custom_command(
            OUTPUT ${_out}
            COMMAND ${SLANGC_EXE} ...
            DEPENDS ${SRC} ${_common_deps}     # ← 把 common/* 都加进来
            COMMENT "slangc ${_rel}"
            VERBATIM
        )
        ...
    endforeach()
endfunction()
```

代价：编辑任意 common 模块 → 所有 entry-point 重编。M4 的 entry-point 数量不多（<10），全量编也几秒级。**强烈推荐 M4.0 前先合入此修改**。

# 风险 / 退路

| 风险 | 退路 |
|---|---|
| Deferred lighting 把 transparent forward 路径砍了之后，Sponza 的 alpha-blend 帘子变成 alpha-mask 显得突兀 | 短期：用力 cutoff（alphaMode=mask 强制），看着勉强；M5 之前再加回 transparent forward |
| SSGI 性能不够 60 fps | 1. SAMPLE_COUNT 4；2. half-res SSGI + bilateral upsample；3. 先 disable SSGI 留 SSAO+SSR |
| SSR thickness 调不对 → 反射漏 / 鬼影 | 默认值给到工业经验值（thickness ≈ 1% scene 直径）；UI 实时调 |
| 第一帧 hdrPrev 未初始化 → SSR 反射黑斑 | 启动时 vkCmdClearColorImage(hdrPrev, 0)；并在 SSR fade 里包含 a 通道 |
| linear march 在长距离反射阶梯感强 | 不修；记录在 Task 13 已知瑕疵；M5 之前加 Hi-Z |
| validation 抱怨 layout transition | 把每 phase 的 transition 集中到一个命名 helper，写注释 |
| GBuffer normal 的 metallic / dielectric 在 R8 albedo 上精度不足导致深色金属反射怪 | 先观察；如有问题改 RT0 = R10G10B10A2_UNORM 或 R16G16B16A16_SFLOAT |
