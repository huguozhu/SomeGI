# M5 — RSM（Reflective Shadow Maps）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 Dachsbacher & Stamminger 2005 的 RSM —— 把单方向光（sun）的 shadow map 升级成"光源视角的 GBuffer"，每 texel 携带 (worldPos, worldNormal, flux=albedo·sunColor)；屏幕像素 per-fragment 在 RSM 上以 N 个 disk 样本抽 VPL（virtual point lights）累积一次反弹漫反射间接光。RSM 是经典的 single-bounce GI 技术，特别适合受 sun 强光的场景（户外 / 大窗户的室内）。

**Architecture:**
- 新增 `RsmTechnique : IGITechnique`：onAttach 分配 RSM 资源 + 设置 light camera；prepare 每帧从 sun 视角渲染 RSM（sun 方向 / 场景动时刷新 —— M5.0 直接每帧渲，后续可加 dirty 标记跳过）；descriptorSetLayout / descriptorSet 把 RSM 资源透传给 LightingPass 的 set=1 的备选位（与 IBL 不冲突，沿用同一个抽象）。
- 新增 `RsmGeometryPass`：从 sun 视角 orthographic 投影渲染场景，MRT 4 张（depth + worldPos + worldNormal + flux）。复用 GBufferPass 已有的描述符 / vertex layout 模式。
- 新增 `RsmSamplePass`：compute，per 屏幕像素抽 RSM 上 N 个 VPL 累加 → rsmGI image (RGBA16F)。
- LightingPass 在 indirect diffuse 路径加一项 lerp 进 RSM gather：`diffuse = lerp(iblDiff, rsmGI, rsm.alpha)` 类似 SSGI 的混合方式（rsm.alpha 是 RSM 对该像素的覆盖置信度）。
- ImGui dropdown 加 "RSM" 选项；其内部（仿 SSGITechnique 的做法）切换到 RSM 时把 RSM 路径打开，下拉选 None/IBL 时关闭。

**Tech Stack:** Vulkan 1.3 (compute, dynamic rendering, MRT), slang, glm。复用 M4 的 `screen_ray` helper 中没有，但可借鉴 SSGI 的 cosine-weighted 抽样模式。

**验证标准:**
1. **M5.0 完成**：RSM 4 张图能 dump 到磁盘看（depth / pos / normal / flux）；从 sun 朝向看下去几何完整、flux 合理（光照强 + albedo 鲜亮的地方更亮）。
2. **M5.1 完成**：RSM gather compute 输出非零的 rsmGI；调试 view（直接把 rsmGI 当输出）能看到一次反弹的轮廓。
3. **M5.2 完成**：GI 下拉选 RSM 时 Sponza 红色帘附近的白柱有红色色溢，效果与 SSGI 类似但来源不同（SSGI 受 screen 限制、RSM 受 sun frustum 限制 —— 互补）。

**M5 不做:**
- 多光源 RSM（每光源一张 RSM）。M5 只接 sun。
- 点光 / 聚光的 RSM。
- RSM cascade（多分辨率）。
- 时序累积。
- Indirect shadows（VPL 之间互遮挡）。
- Multi-bounce。

## Task 2: rsm_geometry.slang

**Files:**
- Create: `shaders/gi/rsm/rsm_geometry.slang`

VS：sun 视角 ortho viewProj（在 push constant 或 per-frame UBO 里）。
PS：MRT 输出 worldPos, worldNormal, flux=baseColor·sunColor·NdotL。

- [ ] **Step 1: 写 shader 骨架**

```hlsl
import shared_types;
import gbuffer_layout;   // 仅 vec3 helpers，可选

[[vk::binding(0, 0)]] ConstantBuffer<RsmFrameUniforms> gRsm;   // sun viewProj 等
[[vk::binding(1, 0)]] StructuredBuffer<MaterialGpu> gMaterials;
[[vk::binding(2, 0)]] SamplerState gLinear;
[[vk::binding(3, 0)]] Texture2D gTextures[];

[[vk::push_constant]] PushConsts gPC;   // model + materialIndex（同 forward）

struct VsIn { ... };
struct VsOut {
    float4 svPos    : SV_Position;
    float3 worldPos : TEXCOORD0;
    float3 normal   : TEXCOORD1;
    float2 uv       : TEXCOORD2;
    nointerpolation int matIndex : TEXCOORD3;
};

[shader("vertex")]
VsOut vs_main(VsIn i) { /* 同 gbuffer.slang，但 viewProj 用 gRsm.sunViewProj */ }

struct RsmOut {
    float4 rt0 : SV_Target0;   // worldPos
    float4 rt1 : SV_Target1;   // worldNormal
    float4 rt2 : SV_Target2;   // flux
};

[shader("pixel")]
RsmOut ps_main(VsOut i) {
    MaterialGpu m = gMaterials[i.matIndex];
    float3 albedo = (m.baseColorFactor * sampleTex(m.baseColorTex, i.uv)).rgb;
    float3 N = normalize(i.normal);
    float NdotL = max(0, dot(N, normalize(-gRsm.sunDir.xyz)));
    float3 flux = albedo * gRsm.sunColor.rgb * gRsm.sunIntensity * NdotL;
    RsmOut o;
    o.rt0 = float4(i.worldPos, 1.0);
    o.rt1 = float4(N, 0);
    o.rt2 = float4(flux, 1.0);
    return o;
}
```

`RsmFrameUniforms` 是 RSM 专用的小 UBO（sunViewProj + sunDir + sunColor·intensity）。

# M5.1 — RSM Sample Compute

把 RSM 当输入，per 屏幕像素抽 N 个 VPL 累积一次反弹间接光。

## Task 5: rsm_sample.slang

**Files:**
- Create: `shaders/gi/rsm/rsm_sample.slang`

算法（标准 RSM gathering）：
1. 屏幕像素从 GBuffer 取 worldPos / worldNormal。
2. 把 worldPos 投到 sun light space，得到 RSM 的中心 UV `centerUv`。
3. 在 `centerUv` 周围的 disk 上抽 N 个低差异序列样本 `(xi, yi)`：
   - 实际 UV = centerUv + (xi, yi) * radius
   - radius 是 ImGui 可调的"采样半径"
4. 每个样本读 (worldPos_vpl, worldNormal_vpl, flux_vpl) 三张图。
5. 按 RSM 论文公式累加：
   ```
   E += flux_vpl * max(0, dot(N_vpl, p - p_vpl)) * max(0, dot(N, p_vpl - p)) / |p - p_vpl|^4
   ```
   （注：实现里通常给分母加 epsilon、给 weight 加 sample_offset_norm 以便重要性采样补偿）。
6. E /= N，乘 albedo（在 lighting.slang 里乘）→ 输出到 rsmGI。

```hlsl
// shaders/gi/rsm/rsm_sample.slang
[[vk::binding(0, 0)]] ConstantBuffer<FrameUniforms> gFrame;
[[vk::binding(1, 0)]] Texture2D<float4> gNormalRough;     // GBuffer
[[vk::binding(2, 0)]] Texture2D<float>  gDepth;
[[vk::binding(3, 0)]] Texture2D<float4> gRsmPosition;
[[vk::binding(4, 0)]] Texture2D<float4> gRsmNormal;
[[vk::binding(5, 0)]] Texture2D<float4> gRsmFlux;
[[vk::binding(6, 0)]] SamplerState      gLinearClamp;
[[vk::binding(7, 0)]] ConstantBuffer<RsmFrameUniforms> gRsm;
[[vk::binding(8, 0)]] RWTexture2D<float4> gOutRsmGI;

struct RsmSamplePC {
    uint2 outSize;
    float2 invOutSize;
    float radius;       // disk 半径，sun light space 单位
    uint  sampleCount;
    float intensity;    // 强度倍率（UI）
};
[[vk::push_constant]] RsmSamplePC gPC;

float2 hammersley(uint i, uint N) { /* 标准实现 */ }

[shader("compute")][numthreads(8,8,1)]
void cs_main(uint3 dt : SV_DispatchThreadID) {
    if (dt.x >= gPC.outSize.x || dt.y >= gPC.outSize.y) return;
    uint2 pix = dt.xy;
    float depth = gDepth.Load(int3(pix, 0));
    if (depth >= 1.0) { gOutRsmGI[pix] = 0; return; }

    float3 p = worldFromDepth(pix, depth);          // helper 同 lighting.slang
    float3 N = normalize(gNormalRough.Load(int3(pix, 0)).xyz);

    // p → sun light space → RSM UV
    float4 lp = mul(gRsm.sunViewProj, float4(p, 1));
    float3 lndc = lp.xyz / lp.w;
    float2 centerUv = lndc.xy * 0.5 + 0.5;

    float3 sumE = float3(0);
    uint hits = 0;
    for (uint i = 0; i < gPC.sampleCount; ++i) {
        float2 xi = hammersley(i, gPC.sampleCount);
        // 把单位圆样本（重新映射 [0,1]→[-1,1] disk）放到 centerUv 周围
        float r = sqrt(xi.x);
        float phi = 6.2831853 * xi.y;
        float2 offset = float2(r*cos(phi), r*sin(phi)) * gPC.radius;
        float2 uv = centerUv + offset;
        if (any(saturate(uv) != uv)) continue;

        float3 p_vpl = gRsmPosition.SampleLevel(gLinearClamp, uv, 0).xyz;
        float3 N_vpl = normalize(gRsmNormal.SampleLevel(gLinearClamp, uv, 0).xyz);
        float3 flux_vpl = gRsmFlux.SampleLevel(gLinearClamp, uv, 0).rgb;

        float3 dir = p - p_vpl;
        float dist2 = max(dot(dir, dir), 1e-3);
        float3 dirN = dir / sqrt(dist2);

        float c1 = max(0, dot(N_vpl, dirN));
        float c2 = max(0, dot(N, -dirN));

        // RSM 论文权重：weight = c1 * c2 * |xi|² / dist^4
        // 这里 |xi|² 是为了重要性采样补偿（中心样本 dist 小、贡献大要降权）。
        float3 contrib = flux_vpl * c1 * c2 * dot(offset, offset) / (dist2 * dist2);
        sumE += contrib;
        hits++;
    }

    float w = hits > 0 ? float(hits) / float(gPC.sampleCount) : 0.0;
    gOutRsmGI[pix] = float4(sumE * gPC.intensity, w);
}
```

## 风险 / 退路

| 风险 | 退路 |
|---|---|
| sun camera 的 ortho frustum 不对 → RSM 渲染歪 | 多 dump 一帧用 RenderDoc 看，调整 lookAt + ortho 参数 |
| RSM 噪点强（64 sample 不够） | 复用 lighting.slang 的 5×5 bilateral；或加专门的 spatial filter |
| sun frustum 覆盖不到的物体收不到 RSM 间接光 | 接受（IBL 已经在那兜底了）；后续 cascade RSM |
| sun 方向在每帧变化（动画 / UI 调整）→ 每帧重渲 RSM 浪费 | 加 dirty flag，sunDir 不变 + scene 不变就跳过 m_rsmGeom.record |
| RSM 4 张 image (512² × ~32B) ≈ 32 MB 显存 | 可调 256² 减到 8 MB；对 sun 视角而言 256² 也通常够 |
